# Day 3 — Review the forecasting dataset

Reviewed Dingdong's release card, published Parquet splits, technical paper, and example rows in the training viewer. The [forecasting data review](../freshretailnet-forecasting.md) records the license, fields, and when each field is available for a next-day forecast.

The initial benchmark will use lagged sales and calendar features. Historical stockout flags support a separate demand-recovery experiment. A training row with zero daytime stockout hours still shows flags outside that window, so any full-day availability check needs the hourly array. Benchmark sales stay in normalized units.

Day 4 will load a reproducible training subset and check the schema and hour conventions against the Parquet data. The evaluation split stays reserved for final reporting.
